Public Facebook Pages as JSON or CSV, no login.

Open-source scraper for public Facebook Pages. Contacts, followers, verified badge, confirmed owner, rating and the latest posts with exact reactions, comments and shares. Three engines, one documented output schema.

View on GitHub Read the docs
Before you scrape: Facebook's robots.txt disallows crawlers and Meta's terms forbid automated collection without permission. This tool reads only what a public Page shows any logged-out visitor, never logs in, skips personal profiles and collects nothing about the people who interact with a Page — but whether your use is allowed depends on where you are and what you do with the data. Check first.
What to expect: every row comes from the data a Page embeds in its own page, read by type. Measured live on 2026-10-06 from an ordinary residential IP with no key and no proxy: 10 Pages and their 30 posts in 50 seconds. Follower counts are rounded by Facebook ("39M") and reported as such; post counts are exact. A logged-out visitor is shown three posts per Page. Full details in the README.

Risk management

Infrastructure, when you want it

PROXIES

Long lists of Pages from several addresses: 2captcha.com/proxy residential exits in .env or --proxy-file — rotated per Page, with per-exit failure tracking and masked logs.

SCRAPER API

No browser at all: --scraper-api fetches each Page from 2Captcha's side, one HTTP call each — the Page and its first post.

SCRAPING BROWSER API

A remote browser session over CDP with its own proxy, fingerprint, and captcha auto-solve bundled — one --cdp-endpoint flag.

FINGERPRINTS

Optional: a 2Captcha Fingerprint API profile, picked by OS and country, applied as a locally-launched browser's user agent.

Get started

# clone and install — no key needed to start
git clone https://github.com/2scraper/facebook-pages-scraper.git
cd facebook-pages-scraper && pip install -r requirements-playwright.txt && playwright install chromium

# one Page and its 3 latest posts
python3 playwright_scraper.py --url nike --posts 3

# a list of Pages, as CSV
python3 playwright_scraper.py --urls-file pages.txt --format csv --out pages.csv

# run again later and see what changed: followers, contacts, post engagement
python3 diff_runs.py pages_monday.csv pages_tuesday.csv
